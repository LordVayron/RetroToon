# Security Policy / Política de seguridad

## Supported versions / Versiones soportadas

Only the latest published release receives security fixes. / Solo la versión publicada más reciente recibe correcciones de seguridad.

## Reporting / Reportes

Please do not publish an exploitable vulnerability in a public issue. Use GitHub's **Security → Report a vulnerability** private reporting feature. Include the affected version, operating system, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

No publiques una vulnerabilidad explotable en un issue público. Usa la función privada **Security → Report a vulnerability** de GitHub. Incluye versión afectada, sistema operativo, pasos para reproducir, impacto y posible mitigación. Los mantenedores confirmarán un reporte completo tan pronto como sea posible y coordinarán su publicación después de disponer de una solución.

Never include playlist URLs, exported settings, personal data, or credentials in a report. / Nunca incluyas URLs de playlists, configuraciones exportadas, datos personales ni credenciales en un reporte.
